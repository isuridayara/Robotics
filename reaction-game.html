Reaction Time Game

This project is an Arduino-based reaction time game built using the Wokwi simulator. The system randomly lights LEDs and the user must press the correct button as fast as possible.

🔧 Features

  • Random LED activation
  • Button input detection
  • Score tracking
  • Buzzer sound feedback
  • 7-Segment display output

🛠 Technologies Used

  • Arduino (C/C++)
  • Wokwi Simulation
