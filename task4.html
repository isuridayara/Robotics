Restricted Area Security Alarm

Task 4: Alert & Notification System

Project Overview

This project addresses home and industrial safety by creating a restricted-zone monitor. It utilizes an ultrasonic sensor to detect movement within a 20cm range, triggering an immediate audible siren and visual flash to deter unauthorized entry.

Technical Logic

Drawing from Lesson 4.1 (Passive Buzzer) in the KS0530 Manual, the system uses the tone() function to oscillate between two frequencies (1000Hz and 500Hz). This creates a distinct "police siren" effect rather than a flat beep, which is more effective for emergency notifications.
