Memory Game

Arduino-based Memory Game that LED Blinking implemented in Wokwi simulator. This project demonstrates basic control of LEDs using Arduino code, timing, and loop logic.

🔧 Features

  • Control single or multiple LEDs
  • Set blink speed using code
  • Learn timing and loop structures in Arduino
  • Simulated on Wokwi for easy testing

🛠 Technologies Used

  • Arduino (C/C++)
  • Wokwi Simulation
