Manual Override & User Interaction

Task 3: Responding to Human Input

Project Overview

This project simulates a "Maintenance Mode" or "Manual Override" for an automated ventilation window. It explores how humans interact with autonomous machines to take control during specific events or system testing.

Technical Logic

Using the Button Module (Lesson 3.1) and Servo Motor (Lesson 9) from the KS0530 Manual, the system implements a toggle switch. The INPUT_PULLUP configuration ensures stable readings without needing external resistors.
