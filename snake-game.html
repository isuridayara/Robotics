Snake Game

Classic Snake game implemented in JavaScript and HTML5 Canvas. The snake grows when it eats food, and the game ends when the snake hits the wall or itself.

🔧 Features

  • Real-time snake movement using arrow keys
  • Food placement at random positions
  • Score tracking
  • Collision detection (wall and self)
  • Playable in browser and on Wokwi simulator

🛠 Technologies Used

  • JavaScript
  • HTML5 Canvas
  • Wokwi Simulation
