🚀 My Weekly Projects

Reaction Time Game

Test your reflexes with this interactive Arduino-based game. LEDs light up randomly and you must press the corresponding button as quickly as possible. Scores are tracked in real-time to challenge your reaction speed.

Snake Game

Classic Snake game implemented in JavaScript and HTML5 Canvas. Control the snake with arrow keys, eat food to grow, and avoid colliding with walls or yourself. Perfect for practicing game logic and canvas drawing.

Memory Game

Train your memory and concentration with this interactive Arduino-based game. Match the correct sequence of LED flashes by pressing the corresponding buttons. The sequence length increases as you progress, making the game more challenging.

Smart Temperature Alert System

This project monitors temperature using a sensor and activates an LED and buzzer if the temperature exceeds a safe threshold. It simulates a simple environmental safety system used in smart homes or server rooms.

Automatic Night Light

An Arduino system that automatically turns on lights when the environment becomes dark using an LDR sensor.

Smart Parking Sensor

A parking assist system using an ultrasonic sensor that warns drivers when they are too close to an obstacle.
