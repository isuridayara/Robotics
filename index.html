Weekly Projects

01 — Weekly builds  ·  6 projects

⚡

Reaction Time Game

Test your reflexes with this interactive Arduino-based game. LEDs light up randomly and you must press the corresponding button as quickly as possible. Scores are tracked in real-time.

🐍

Snake Game

Classic Snake game implemented in JavaScript and HTML5 Canvas. Control the snake with arrow keys, eat food to grow, and avoid colliding with walls or yourself.

🧠

Memory Game

Train your memory and concentration with this interactive Arduino-based game. Match the correct sequence of LED flashes by pressing the corresponding buttons.

🌡️

Smart Temperature Alert System

Monitors temperature using a sensor and activates an LED and buzzer if the temperature exceeds a safe threshold. Simulates an environmental safety system for smart homes.

💡

Automatic Night Light

An Arduino system that automatically turns on lights when the environment becomes dark using an LDR sensor.

🚗

Smart Parking Sensor

A parking assist system using an ultrasonic sensor that warns drivers when they are too close to an obstacle.

🚗

Traffic Light Simulation with Pedestrian Button

Traffic light control systems are one of the most widely deployed embedded systems in the world. The same logic running on this Arduino powers infrastructure across cities globally.
