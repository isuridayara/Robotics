Smart Parking Sensor

This Arduino-based parking assist system uses an ultrasonic sensor to measure the distance between a vehicle and nearby obstacles. When the object gets too close, a buzzer alert is triggered to warn the driver and prevent collisions.

🔧 Features

  • Real-time distance measurement using ultrasonic sensor
  • Sound alert when the vehicle gets too close
  • Serial monitor displays measured distance
  • Simulated easily using the Wokwi platform

🛠 Technologies Used

  • Arduino UNO
  • HC-SR04 Ultrasonic Sensor
  • Buzzer
  • Wokwi Simulation
