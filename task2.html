Adaptive Grow-Light System

Variable Control & Automation

Project Overview

This project implements a Variable Control System that dynamically adjusts grow-light intensity based on ambient sunlight, optimizing energy efficiency in smart agriculture.

Working Principle

The system uses Pulse Width Modulation (PWM) on Pin D3. As the Photoresistor (A0) detects less light, the LED brightness increases automatically.
