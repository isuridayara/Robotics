Adaptive Grow-Light System

Variable Control & Automation

Project Overview

In modern smart agriculture, supplemental lighting is essential for plant growth during cloudy days or nighttime. However, constant lighting is energy-inefficient. This project implements a Variable Control System that dynamically adjusts the grow-light intensity based on the amount of natural sunlight detected in the environment.

Components Used

  • Keyestudio UNO Board
  • Photoresistor Module (Ambient Light Sensor)
  • Yellow LED Module (as the Grow-Light)
  • USB Data Cable

Technical Implementation

Pin Mapping: The Photoresistor is mapped to Analog Pin A0 to read variable light intensity[cite: 1, 88]. The LED is connected to Digital Pin D3, which supports PWM (Pulse Width Modulation)[cite: 1, 69].

The system utilizes PWM technology to obtain analog-style results through digital methods[cite: 1, 151]. By modulating the duty cycle between 0 (off) and 255 (full brightness), the system can create a smooth transition in light intensity[cite: 1, 150].

Dynamic Logic

The UNO board reads the analog value from the photoresistor (0–1023). As natural light decreases, the resistance of the photoresistor increases[cite: 1, 205]. The code then maps this input to an inverse PWM output: Lower ambient light = Higher LED brightness. This ensures plants receive a consistent level of light while minimizing power consumption during sunny periods.
