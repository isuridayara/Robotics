Smart Sensor Display System

Task 5: Display & Information System

Project Overview

This project builds a real-time information display system on Arduino Uno. An HC-SR04 ultrasonic sensor continuously measures distance, while an LDR (Light Dependent Resistor) reads ambient light levels. All data is presented live on a 16×2 I²C LCD screen, with three colour-coded LEDs acting as instant visual status indicators — green for clear, yellow for caution, and red for close-range alert.

The system demonstrates how embedded displays and multi-sensor fusion can create a compact monitoring panel, similar to dashboards found in smart home devices and industrial equipment.

Where Is This Used?

Display and information systems like this one are everywhere in the real world. Any time a device needs to show sensor data to a person — without a phone or computer screen nearby — an embedded display system is the answer. Here are some common places this exact kind of project appears:

🏠 Smart Home

Indoor air quality monitors and room occupancy sensors display live readings on a small LCD panel.

🏭 Industrial Safety

Factory floor panels show proximity alerts when workers enter restricted machine zones.

🚗 Vehicle Systems

Parking sensors display distance to obstacles on a dashboard screen with colour-coded warnings.

🌱 Agriculture

Greenhouse monitors show soil moisture, light intensity, and temperature on field displays.

🏥 Healthcare

Bedside monitors display patient environment data — light levels, motion — with instant LED alerts.

🤖 Robotics

Autonomous robots show their sensor readings on an onboard display for live diagnostics.

What Each Component Does

Each part of the circuit has a specific role in collecting, processing, and presenting information:

Arduino Uno

The Brain

Reads all sensor inputs, runs the decision logic, and tells every other component what to do. It runs the loop() function every 500 ms — collecting data, calculating values, updating the display, and switching the correct LED on or off.

HC-SR04

Ultrasonic Distance Sensor

Emits a short burst of ultrasound from the TRIG pin, then listens on the ECHO pin for the reflection. The time gap between send and receive tells the Arduino exactly how far away an object is — the same principle used in car parking sensors and automatic doors.

LDR

Light Dependent Resistor

A resistor whose resistance drops as light increases. Paired with a fixed 10 kΩ resistor, it forms a voltage divider — brighter light means a higher voltage at pin A0. The Arduino reads this as a number from 0 to 1023 and converts it to a 0–100% brightness percentage.

LCD 16×2

Information Display

A 16-character, 2-row screen that shows the sensor values in plain text. The I²C backpack reduces the wiring to just two data lines (SDA and SCL), making it easy to add to any project. Row 0 shows the distance reading and row 1 shows light level plus a status word.

LEDs × 3

Visual Status Indicators

Green, yellow, and red LEDs give an instant at-a-glance status without needing to read the screen. Green means the area is clear (>30 cm), yellow is a caution zone (15–30 cm), and red means something is very close (≤15 cm). Each LED has a 220 Ω resistor to limit current and prevent damage to the Arduino pin.

LCD Display Output

The 16×2 LCD updates every 500 ms with live sensor readings and a plain-English status word:

Light: 78% OK

Technical Logic

Drawing from Lesson 3.1 (Ultrasonic Sensor) and Lesson 5.2 (LCD Display) in the KS0530 Manual, the system uses pulseIn() to calculate distance from sound travel time: distance = duration / 58.2. The LDR is read via analogRead(A0) and scaled to 0–100% using map().

The LiquidCrystal_I2C library drives the display over the I²C bus (address 0x27), keeping wiring minimal — only two data wires needed. LED thresholds are set at <15 cm (red alert), 15–30 cm (yellow caution), and >30 cm (green clear).

Arduino Code

#include <Wire.h>
#include <LiquidCrystal_I2C.h>

// ── Pin definitions ───────────────────────────
const int TRIG_PIN  = 9;
const int ECHO_PIN  = 10;
const int LDR_PIN   = A0;
const int LED_GREEN = 2;
const int LED_YELL  = 3;
const int LED_RED   = 4;

// LCD: I²C address 0x27, 16 cols, 2 rows
LiquidCrystal_I2C lcd(0x27, 16, 2);

void setup() {
  pinMode(TRIG_PIN,  OUTPUT);
  pinMode(ECHO_PIN,  INPUT);
  pinMode(LED_GREEN, OUTPUT);
  pinMode(LED_YELL,  OUTPUT);
  pinMode(LED_RED,   OUTPUT);

  lcd.init();
  lcd.backlight();

  // Startup splash screen
  lcd.setCursor(0, 0); lcd.print("  Smart Sensor  ");
  lcd.setCursor(0, 1); lcd.print("  Display  v1   ");
  delay(2000);
}

long getDistance() {
  digitalWrite(TRIG_PIN, LOW);  delayMicroseconds(2);
  digitalWrite(TRIG_PIN, HIGH); delayMicroseconds(10);
  digitalWrite(TRIG_PIN, LOW);
  long dur = pulseIn(ECHO_PIN, HIGH);
  return dur / 58.2; // microseconds → centimetres
}

void updateLEDs(long dist) {
  digitalWrite(LED_GREEN, dist > 30);
  digitalWrite(LED_YELL,  dist > 15 && dist <= 30);
  digitalWrite(LED_RED,   dist <= 15);
}

void loop() {
  long dist  = getDistance();
  int  ldr   = analogRead(LDR_PIN);
  int  light = map(ldr, 0, 1023, 0, 100);

  // Row 0 — distance
  lcd.setCursor(0, 0);
  lcd.print("Dist: "); lcd.print(dist); lcd.print(" cm    ");

  // Row 1 — light level + status word
  lcd.setCursor(0, 1);
  lcd.print("Light:"); lcd.print(light); lcd.print("%  ");
  lcd.print(dist <= 15 ? "ALERT" : dist <= 30 ? "NEAR " : "OK   ");

  updateLEDs(dist);
  delay(500);
}

How It Works

  1. Startup splash — On power-up the LCD shows "Smart Sensor Display v1" for 2 seconds, confirming the I²C screen is wired and initialised correctly.
  2. Distance measurement — Every 500 ms the HC-SR04 fires a 10 µs ultrasonic pulse. pulseIn() times the echo return; dividing by 58.2 converts travel time to centimetres.
  3. Light reading — The LDR forms a voltage divider with a 10 kΩ resistor. analogRead(A0) returns 0–1023, which map() scales to a 0–100% brightness value.
  4. LCD update — Row 0 shows the distance reading; Row 1 shows light percentage and a plain-English status word: OK, NEAR, or ALERT.
  5. LED indicators — Green lights when distance >30 cm (safe), yellow between 15–30 cm (caution), and red at ≤15 cm (close-range alert) for an instant at-a-glance status.
