Plant Health Warning Light

Robotics & Sensor-Based Application

Project Overview

Inspired by Automated Greenhouse Management, this system identifies a critical real-world need: monitoring environmental safety for crops. This system acts as an automated visual indicator to alert operators when the climate exceeds safe limits.

Technical Implementation

Using the DHT11 sensor from the KS0530 Kit, the system monitors temperature. If it rises above 30°C, Digital Pin D3 triggers the Yellow LED.
