Plant Health Warning Light

Robotics & Sensor-Based Application

Project Overview

Inspired by Automated Greenhouse Management, this system identifies a critical real-world need: monitoring environmental safety for crops. In a greenhouse, extreme temperatures can cause irreversible damage to plants. This system acts as an automated visual indicator to alert operators when the climate exceeds safe limits.

Components Used

  • Keyestudio UNO Board
  • DHT11 Temperature & Humidity Sensor
  • Yellow LED Module
  • 3-pin F-F DuPont Wires

Circuit Design

Following the KS0530 Kit Manual specifications:

  • Sensor: The DHT11 is connected to Digital Pin D7[cite: 1, 2].
  • Output: The Yellow LED Module is connected to Digital Pin D3[cite: 1, 128].
  • Power: Modules are powered via the 5V and GND rails of the UNO board.

Working Principle

The microcontroller reads environmental data from the DHT11 sensor. If the temperature exceeds a predefined "safe" threshold (e.g., 30°C), the UNO board triggers a HIGH digital signal to the LED. This provides an immediate visual warning to the greenhouse operator to check the ventilation systems.
